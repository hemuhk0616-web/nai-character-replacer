GBF ACCOUNT EXPORTER · V4.1

한 번 실행하는
계정 통합 수집기로.

이번 검증판은 무기·소환석·캐릭터를 수집한 뒤, 무기·소환석 창고 목록과 창고 화면 구조까지 자동 확인해 JSON 하나로 저장합니다.

아직 전체 계정 수집 완료판은 아닙니다.
직업·실제 편성과 창고 안의 개별 장비는 아직 미수집입니다. 창고 목록 조회와 개별 장비 수집을 구분해서 기록합니다. 게임에 적용된 필터가 있으면 그 범위만 수집하며, 전체 수량 여부는 아직 미검증입니다.

최초 1회 · 새 실행 북마크 등록

  1. 아래 버튼으로 실행 주소를 복사합니다.
  2. Quetta에 북마크를 하나 만들고 이름을 GBF 통합 수집 V4로 정합니다.
  3. 그 북마크의 주소를 방금 복사한 주소로 바꿉니다. 기존 V3 무기 수집 북마크는 그대로 둡니다.

복사가 안 되면 주소 직접 선택

실행 전 필터 해제

무기·소환석·캐릭터 목록 각각의 필터를 해제해 주세요.
필터가 남아 있으면 해당 조건에 맞는 항목만 수집됩니다. 정렬 순서는 바꾸지 않아도 됩니다. 현재 버전은 필터를 자동으로 해제하지 않습니다.

실행

  1. 로그인된 그랑블루의 무기 보유 목록을 엽니다.
  2. 등록한 GBF 통합 수집 V4 북마크를 누릅니다.
  3. 수집이 끝날 때까지 같은 탭을 열어 둡니다. 자동 저장된 gbf-account-v4-….json 파일을 이 대화에 첨부합니다.

수집 도중 페이지를 직접 바꾸지 마세요. 창고 화면으로 자동 이동했다가 원래 목록으로 돌아오는 과정이 포함됩니다. 자동 다운로드가 안 되면 수집 패널의 JSON 저장을 누르면 됩니다. 중단·시간 초과 후 재시도할 때는 게임을 새로고침해 주세요.

기존 V3.0 수집기는 수정하지 않았습니다. 이 도구는 게임 목록의 기본 로딩 기능만 사용하며, 처분·강화·창고 이동을 실행하지 않습니다. 수집 결과는 외부로 자동 전송하지 않습니다.
