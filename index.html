2. 캐릭터 프롬프트 · 프리셋

벨라 V10과 라비스의 정식 프리셋은 원본 NovelAI V5 PNG 메타데이터를 기반으로 해. 외형·의상만 포함하고 구도·작가 태그는 제외했어. 쉼표로 태그를 구분해.

3. 캐릭터별 프롬프트 · 한 명만 교체

원본의 캐릭터 프롬프트가 발견되면 여기서 한 명을 선택해. 선택하지 않은 인물은 원본 그대로 유지해. 메인 프롬프트의 인원 태그도 보존해.

PNG를 불러오면 캐릭터 슬롯을 확인해.

3. 구도 보정 (선택)

원본 메타데이터에 포즈가 없다면 직접 보완해. 이미지를 보고 자동으로 포즈를 읽는 기능은 아직 없어.

3-1. 태그 분류 · 수동 검토

안전 우선: 명확한 외형·의상만 기본 삭제. 애매한 태그는 유지하며 검토 표시. 태그별 선택을 바꾸면 즉시 결과에 반영돼.

성인향 태그 별도 검토

SAFE에서도 원본은 보존돼. 미인식 태그가 있을 수 있으므로 결과를 직접 확인해.

4. 최종 결과 복사 · V5 생성 설정

캐릭터 프리셋을 선택하면 결과가 갱신돼. 복사 버튼은 각각 NovelAI 입력칸에 사용해.

① 생성 설정

NovelAI V5에 입력할 값만 보여줘. 값을 바꾸면 복사용 설정에도 반영돼.

PNG를 불러오면 표시돼.
설정 JSON 원문 보기
PNG를 불러오면 표시됩니다.

설정은 NovelAI에 자동 입력되지 않아. 표시된 값에 맞춰 직접 적용해야 해.

② 메인 프롬프트 · 캐릭터 교체 결과

③ 네거티브 프롬프트 · UC

원본 UC를 그대로 사용해. 캐릭터 충돌은 별도로 검토해 줘.

④ 캐릭터별 프롬프트 · V5

선택한 캐릭터의 외형·의상만 교체하고 나머지 캐릭터 슬롯은 보존해. NovelAI 캐릭터 프롬프트 칸에 각각 입력해야 해.
