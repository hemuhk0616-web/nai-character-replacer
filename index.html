2. 캐릭터 프롬프트 · 프리셋

벨라·라비스는 Lite(간결한 태그)와 Full(원본 메타데이터 상세 태그) 두 가지 버전이 있어. 외형·의상만 포함하고 구도·작가 태그는 제외했어. 쉼표로 태그를 구분해.

제외 태그 없음

3. 캐릭터별 프롬프트 · 최대 두 명 교체

원본 캐릭터 슬롯 중 최대 두 명을 서로 다른 프리셋으로 교체해. 선택하지 않은 인물은 원본 그대로 유지해. 메인 프롬프트의 인원 태그도 보존해.

두 교체 대상은 서로 달라야 해. 두 번째 캐릭터에는 선택한 프리셋의 외형·의상·자연어 보조를 적용하며, 첫 번째 캐릭터와 의상 옵션은 공유해.

PNG를 불러오면 캐릭터 슬롯을 확인해.

3. 구도 보정 (선택)

원본 메타데이터에 포즈가 없다면 직접 보완해. 이미지를 보고 자동으로 포즈를 읽는 기능은 아직 없어.

원본 프레이밍 보정 (실험)

원본 이미지에서 카메라가 잡은 범위와 인물의 화면 배치를 직접 입력해. 이미지에서 자동 추출하지 않으며, 원본 포즈 태그는 유지해. 이 설명은 메인 프롬프트에만 추가돼.

3-1. 태그 분류 · 수동 검토

쉼표로 구분 · 원본은 변경하지 않고 결과에만 추가해.
